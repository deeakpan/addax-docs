# Addax

Addax is a perpetual order book. Bids and asks rest on the book. A trade happens when an order matches one that is already there.

You log in with [Para](https://www.getpara.com/). MetaMask and social login both open the same kind of embedded wallet. That wallet is the address Addax uses for your margin and your orders. Mainnet and testnet use this login.

ADDX and zkLTC can be posted as collateral. Addax routes both into USDC on Ethereum before the position is opened. ADDX stakers receive 40% of protocol fees.

The Addax fee is up to 0.1% of the filled size. Funding is paid between traders once an hour.

Addax is built on [Lighter](https://lighter.xyz/).

To try the current chain build, open [Starting on testnet](testnet/start.md).
