# Testnet network

Addax testnet runs on **LitVM**.

| Parameter | Value |
|---|---|
| Network name | LitVM |
| Chain ID | `4441` |
| RPC (HTTP) | `https://liteforge.rpc.caldera.xyz/http` |
| RPC (WebSocket) | `wss://liteforge.rpc.caldera.xyz/ws` |
| Block explorer | `https://liteforge.explorer.caldera.xyz` |
| Native gas token | `zkLTC` |

Log in with [Para](https://www.getpara.com/) first, using MetaMask or a social account, so the embedded wallet exists. Then add this network in that wallet, or approve the prompt in the app.

You need zkLTC for gas. Claim it from [Get zkLTC](../getting-started/faucet.md).
