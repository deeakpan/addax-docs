# Starting on testnet

Testnet uses the same login as mainnet.

1. Open Addax and continue with [Para](https://www.getpara.com/).
2. Connect MetaMask, or use a social login.
3. Para opens your embedded wallet. The same login returns the same wallet later.
4. Add the LitVM network. Details are on [Network](network.md).
5. Claim zkLTC for gas from the [faucet](../getting-started/faucet.md).
6. Get test collateral and approve it. Testnet trades use the LitVM vaults and DIA prices, not the mainnet order book. See [DIA prices](oracle.md).

MetaMask, if you use it, is the login method. The embedded wallet is still the Para wallet for your account.
