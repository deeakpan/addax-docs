# Log in

Mainnet and testnet use the same login.

Open Addax and continue with [Para](https://www.getpara.com/). You can connect MetaMask, or you can use a social login. Para creates an embedded wallet for that login. The same login returns the same embedded wallet.

That embedded wallet is the address for your margin and for the orders you sign. MetaMask is only a way to log in. It does not replace the embedded wallet.

On mainnet, the embedded wallet is the Para wallet that holds the USDC margin after ADDX or zkLTC has been routed in.

On testnet, you use the same Para login, then open [Starting on testnet](../testnet/start.md) to add LitVM and claim gas.
